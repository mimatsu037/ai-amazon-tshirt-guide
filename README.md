# AI×Amazon おうちTシャツ販売スタートガイド

30〜40代の主婦向けに、AIとCanvaを使ってAmazon向けTシャツ商品を形にする流れを5STEPでまとめたスマホ対応ガイドです。

## 内容

- テーマ選びから出品準備までの5STEP
- タップして開けるChatGPTプロンプト
- 保存できるチェックリスト
- Tシャツデザイン例のスワイプギャラリー
- Canvaの実操作動画とTシャツ選択画面
- LINE登録者限定5大特典への案内

## 公開サイト

- Sites: https://mina-ai-tshirt-guide.sixtones-hokuhoku-mi.chatgpt.site

## 構成

ビルド不要の静的HTMLサイトです。`index.html`をブラウザで開くと表示できます。
